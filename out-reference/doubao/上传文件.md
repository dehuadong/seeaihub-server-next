`POST https://ark.cn-beijing.volces.com/api/v3/files`

上传文件到方舟平台，供后续模型调用作为输入（如图像、视频、文档等）。文件在一定时间后过期删除。

<span id=".6Ym05p2D"></span>
## 鉴权

本接口支持鉴权方式如下，详情请参见 [Base URL 及鉴权](https://docs.volcengine.com/docs/82379/1298459)。


* API Key 鉴权，请在 [API Key 管理](https://console.volcengine.com/ark/region:cn-beijing/apiKey) 页面，获取长效 API Key。

## 请求参数

<span id=".Ym9keS3lj4LmlbA="></span>
### Body 参数


**file** `object` `必选`  |  上传的文件

需要上传的文件，要求为二进制文件。具体限制请参见 Files API 教程

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">注意</div>


<div data-tips="true" data-tips-type="tip">文件上传支持二进制文件和文件 URL 两种传入方式，<code>file</code>、<code>url</code> 为二选一必填参数，不可同时传参。</div>




**purpose** `string` `必选`  |  文件用途

文件用途。`user_data`：可以灵活使用的文件，能够用于任意用途



**expire_at** `integer`  |  文件过期时间

设置存储的有效期，需要传入 UTC Unix 时间戳（单位：秒）。最少保留 1 天，最多保留 30 天；不传时默认保留 7 天（当前时刻 + 604800）

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">注意</div>


<div data-tips="true" data-tips-type="tip">取值范围：<code>[当前时刻+86400, 当前时刻+2592000]</code>，即最少保留 1 天，最多保留 30 天。不传时默认保留 7 天（当前时刻 + 604800）。</div>




**preprocess_configs** `object`  |  预处理配置

用于设置不同文件类型的预处理规则


**video** `object`  |  视频预处理配置

`preprocess_configs.video`

视频预处理相关配置。配置 `model` 字段后，系统将根据对应模型的抽帧策略，自动填充 `max_video_tokens`、`min_frame_tokens`、`max_frame_tokens`、`min_frames` 四个字段的默认值


**fps** `number` `默认值 1`  |  抽帧帧率

`preprocess_configs.video.fps`

每秒钟从视频中抽取指定数量的图像。取值越高，对于视频中画面变化理解越精细；取值越低，对于视频中画面变化感知减弱，但是使用的 token 花费少，速度也更快。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">注意</div>


<div data-tips="true" data-tips-type="tip">取值范围：<code>[0.2, 5]</code>。单视频 token 用量范围在 <code>[10k, 80k]</code>。</div>




**model** `string`  |  预处理模型

`preprocess_configs.video.model`

使用该文件进行推理时，要使用的视频理解模型 ID（Model ID）或 Endpoint ID。传入不同的模型 ID 会采用不同的抽帧策略。不传该参数时默认采用 `doubao-seed-1.8` 之前的模型对应的抽帧策略

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">注意</div>


<div data-tips="true" data-tips-type="tip">Files API 中设置的模型 ID 与推理使用的模型 ID 不强耦合，只影响上传视频文件时预处理抽帧策略。如需处理视频中的音频内容，该字段需指定为支持音频理解的模型。</div>






**tos** `object`  |  TOS 存储配置

文件存储的 TOS 信息。TOS 即火山引擎对象存储服务；配置本参数后，上传文件将存储至用户指定的火山引擎对象存储 TOS Bucket 中，不再存入方舟平台默认托管存储空间

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">注意</div>


<div data-tips="true" data-tips-type="tip">不传 <code>tos</code> 参数：文件存储在方舟平台托管的默认存储空间，单文件不超过 512 MB。已存入方舟平台托管存储的历史文件，不会自动迁移至其他存储位置。</div>


<div data-tips="true" data-tips-type="tip">传 <code>tos</code> 参数：文件存储在用户指定的火山引擎对象存储 TOS Bucket 中，视频文件不超过 2 GB，其他类型文件不超过 512 MB。授权写入用户指定 TOS Bucket 中的文件，不支持在 TOS 侧删除或修改；如需删除文件，可调用 Files API 删除。</div>



**bucket** `string`  |  存储桶名称

`tos.bucket`

目标文件待写入的 TOS 存储桶名称，该存储桶需提前完成创建



**prefix** `string`  |  存储路径前缀

`tos.prefix`

文件在目标 TOS 存储桶内的存放前缀路径，入参填写相对路径格式，上传后文件将落地至该前缀目录下。示例：`arkfiles/`




**url** `string`  |  文件 URL

文件 URL，支持 HTTP/HTTPS URL（公网可直接访问的文件 URL）以及 TOS URI（格式为 `tos://<bucket>/<prefix>/<file_name>`）

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">注意</div>


<div data-tips="true" data-tips-type="tip">文件上传支持二进制文件和文件 URL 两种传入方式，<code>file</code>、<code>url</code> 为二选一必填参数，不可同时传参。传入 TOS URI 时，必须将文件存储到火山引擎对象存储 TOS Bucket 中，此时 <code>tos.bucket</code>、<code>tos.prefix</code> 为必填参数。</div>

## 响应参数


**created_at** `integer`  |  创建时间

文件创建时间，UTC Unix 时间戳（单位：秒）



**expire_at** `integer`  |  过期时间

文件过期时间，UTC Unix 时间戳（单位：秒）。文件过期后将无法访问，需重新上传



**filename** `string`  |  原始文件名

上传文件的原始文件名



**id** `string`  |  文件 ID

由服务端生成的文件 ID。可在后续接口中通过该 ID 引用文件



**object** `string`  |  对象类型

对象类型，固定为 `file`



**purpose** `string`  |  文件用途

文件用途。`user_data`：可以灵活使用的文件，能够用于任意用途



**status** `string`  |  文件状态

文件生命周期状态。可能的值包括 `processing`（处理中）、`active`（可用）、`failed`（处理失败）等

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">注意</div>


<div data-tips="true" data-tips-type="tip">仅当 <code>status</code> 为 <code>active</code> 时，才能在 Responses API、Chat API 中使用对应的 <code>file_id</code> 进行多模态理解。</div>




**bytes** `integer`  |  文件大小

文件大小，单位为字节



**download_url** `string`  |  下载 URL

由服务端预签名的文件下载地址，指向底层 TOS 对象



**error** `object`  |  错误信息

文件处理失败时的错误详情

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">注意</div>


<div data-tips="true" data-tips-type="tip">仅在 <code>status</code> 为 <code>failed</code> 时返回。</div>



**code** `string`  |  错误码

`error.code`

机器可读的错误码



**message** `string`  |  错误消息

`error.message`

人类可读的错误描述信息



**param** `string`  |  错误参数

`error.param`

触发该错误的请求参数名（如有）



**type** `string`  |  错误类型

`error.type`

错误类型标识




**mime_type** `string`  |  MIME 类型

文件的 MIME 类型，由系统检测或根据上传声明确定


# 图片生成 API

**接口地址**: `POST https://ark.cn-beijing.volces.com/api/v3/images/generations`

本文档介绍 Doubao Seedream 5.0 pro、Doubao Seedream 5.0 lite、Doubao Seedream 4.5 及 Doubao Seedream 4.0 图片生成模型的调用 API，包含输入输出参数、取值范围及注意事项。

---

## 模型能力概览

| 模型 | 核心能力 |
| :--- | :--- |
| **Seedream 5.0 pro** | - **生成单图**（不支持组图）：<br>  * 多图生图：2-10张参考图 + 文本提示词 → 单张图片<br>  * 单图生图：1张参考图 + 文本提示词 → 单张图片<br>  * 文生图：文本提示词 → 单张图片<br>- **交互编辑**：支持通过坐标、框选、箭头等方式指定编辑位置<br>- **不支持**：组图生成、联网搜索、流式输出 |
| **Seedream 5.0 lite**<br>**Seedream 4.5**<br>**Seedream 4.0** | - **生成组图**（`sequential_image_generation` = `auto`）：<br>  * 多图生组图：2-14张参考图 + 文本提示词 → 一组关联图片（参考图数+生成图数 ≤ 15）<br>  * 单图生组图：1张参考图 + 文本提示词 → 一组关联图片（最多14张）<br>  * 文生组图：文本提示词 → 一组关联图片（最多15张）<br>- **生成单图**（`sequential_image_generation` = `disabled`）：<br>  * 多图生图：2-14张参考图 + 文本提示词 → 单张图片<br>  * 单图生图：1张参考图 + 文本提示词 → 单张图片<br>  * 文生图：文本提示词 → 单张图片 |

## 请求参数

### Body 参数

| 参数名 | 类型 | 必选 | 描述 |
| :--- | :--- | :--- | :--- |
| `model` | string | **是** | 模型 ID |
| `prompt` | string | **是** | 提示词。支持中英文，建议不超过300个汉字或600个英文单词。<br>详见：[Seedream 4.0-5.0 提示词指南](https://www.volcengine.com/docs/82379/1829186) |
| `image` | string / string[] | 否 | 参考图片。支持URL或Base64编码，单图或多图。<br>- URL：需可访问<br>- Base64：格式 `data:image/<格式>;base64,<编码>`（格式需小写）<br><br>**图片要求**：<br>- 格式：jpeg、png、webp、bmp、tiff、gif、heic、heif<br>- 宽高比： [1/16, 16]<br>- 宽高长度：> 14 px<br>- 大小：≤ 30MB<br>- 总像素：≤ `6000x6000=36,000,000` px<br><br>**数量限制**：<br>- Seedream 5.0 pro：最多10张<br>- Seedream 5.0 lite / 4.5 / 4.0：最多14张 |
| `size` | string | 否 | 图像尺寸。支持指定分辨率档位（如 `2K`）或宽高像素值（如 `2048x2048`），不可混用。各模型支持详情不同，请参考下文。 |
| `optimize_prompt_options` | object | 否 | 提示词优化配置。<br>- `mode` (string): 优化模式。<br>  * `standard`（默认）：质量更优，耗时较长<br>  * `fast`：耗时更短，适合对时延敏感的业务 |
| `output_format` | string | 否 | 图像文件格式。可选：`png`、`jpeg`（默认）。<br>**支持模型**：Seedream 5.0 pro, Seedream 5.0 lite |
| `response_format` | string | 否 | 返回格式。可选：<br>- `url`（默认）：返回图片下载链接（**24小时内有效**）<br>- `b64_json`：返回Base64编码的JSON数据 |
| `sequential_image_generation` | string | 否 | 组图模式控制。可选：<br>- `auto`：模型自主判断是否返回组图及数量<br>- `disabled`（默认）：关闭组图，只生成一张图<br>**支持模型**：Seedream 5.0 lite, Seedream 4.5, Seedream 4.0 |
| `sequential_image_generation_options` | object | 否 | 组图配置。当 `sequential_image_generation` 为 `auto` 时生效。<br>- `max_images` (integer): 最大生成图片数，默认15，范围[1, 15]。<br>  *注：实际生成数受 `max_images` 和输入参考图数量影响（参考图数+生成图数 ≤ 15）。*<br>**支持模型**：Seedream 5.0 lite, Seedream 4.5, Seedream 4.0 |
| `stream` | boolean | 否 | 流式输出开关。默认 `false`。<br>- `true`：即时返回每张图片结果<br>**支持模型**：Seedream 5.0 lite, Seedream 4.5, Seedream 4.0 |
| `tools` | object[] | 否 | 工具配置。<br>- `type` (string, **必选**): 工具类型。可选 `web_search`（联网搜索）。<br>  *注：开启后模型自主判断是否搜索，提升时效性但增加时延。实际搜索次数可通过 `usage.tool_usage.web_search` 查询。*<br>**支持模型**：Seedream 5.0 lite |
| `watermark` | boolean | 否 | 水印开关。默认 `true`。<br>- `true`：在图片右下角添加“AI 生成”水印<br>- `false`：不添加水印 |

### 各模型 `size` 参数详解

#### Seedream 5.0 pro

- **方式1（推荐）**：指定分辨率档位（`1K`、`2K`），并在prompt中描述宽高比/形状/用途，由模型判断最终大小。**默认值**: `2K`。
- **方式2**：指定宽高像素值（`宽x高`）。
  - 总像素范围：`[1280x720 (921,600), 2048x2048x1.1025 (4,624,220)]`
  - 宽高比范围：`[1/16, 16]`
  - *需同时满足两项限制。*
  - *示例*：`2048x1024`（有效），`512x512`（无效，总像素不足）。

## 响应参数

### 非流式调用响应

| 参数名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `created` | integer | 请求创建时间的Unix时间戳（秒） |
| `model` | string | 本次请求使用的模型ID |
| `data` | object[] | 输出图像的信息数组。组图场景下，每个元素对应一张图片或一次错误。<br>*注：组图生成中某张图失败时，若因审核不通过，不影响其他图片生成；若因内部服务异常（500），则停止后续生成。* |
| `data[].b64_json` | string | 图片的Base64信息（当 `response_format` 为 `b64_json` 时返回） |
| `data[].error` | object | 单张图片生成失败时的错误信息。<br>- `code` (string): 错误码<br>- `message` (string): 错误信息 |
| `data[].output_format` | string | 输出图像格式（`png` 或 `jpeg`）。**支持模型**: Seedream 5.0 pro |
| `data[].size` | string | 图像宽高像素值，格式 `<宽>x<高>` |
| `data[].url` | string | 图片URL（当 `response_format` 为 `url` 时返回）。**24小时内有效**。建议配置[TOS数据订阅](https://www.volcengine.com/docs/6349/1366744)自动转存。 |
| `error` | object | 顶层错误信息，当整个请求未能生成任何图片时返回。<br>- `code` (string): 错误码<br>- `message` (string): 错误信息 |
| `tools` | object[] | 本次请求中配置并被调用的工具列表。<br>- `type` (string): 工具类型（如 `web_search`）。<br>**支持模型**: Seedream 5.0 lite |
| `usage` | object | 用量信息。<br>- `generated_images` (integer): 成功生成图片数（计费依据）<br>- `input_images` (integer): 输入图片张数。**支持模型**: Seedream 5.0 pro<br>- `output_tokens` (integer): 输出token数。计算逻辑：`sum(图片长*图片宽) / 256` 后取整<br>- `tool_usage` (object): 工具用量。<br>  * `web_search` (integer): 联网搜索次数。**支持模型**: Seedream 5.0 lite<br>- `total_tokens` (integer): 总token数（当前与 `output_tokens` 一致） |

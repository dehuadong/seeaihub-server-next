# 查询视频生成任务状态 API 文档

## 接口信息

```
GET https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks/{id}
```

查询视频生成任务的状态。

> **说明：**
> - 仅支持查询最近 7 天的任务记录，时间区间为 [T-7天, T)，其中 T 为请求发起时刻的 UTC 时间戳（精确到秒）。
> - 视频 URL 有效期为 24 小时，请及时下载或转存。

---

---

## 请求参数

**Query String Parameters**（在 URL String 中传入）

| 参数 | 类型 | 是否必选 | 说明 |
|------|------|----------|------|
| `id` | `string` | ✅ 必选 | 您需要查询的视频生成任务的 ID |

---

## 响应参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `id` | `string` | 视频生成任务 ID |
| `model` | `string` | 任务使用的模型名称和版本，格式为 `模型名称-版本` |
| `status` | `string` | 任务状态，详见下方状态说明 |
| `error` | `object / null` | 错误提示信息，成功返回 `null`，失败返回错误数据 |
| `created_at` | `integer` | 任务创建时间的 Unix 时间戳（秒） |
| `updated_at` | `integer` | 任务当前状态更新时间的 Unix 时间戳（秒） |
| `content` | `object` | 视频生成任务的输出内容 |
| `seed` | `integer` | 本次请求使用的种子整数值 |
| `resolution` | `string` | 生成视频的分辨率 |
| `ratio` | `string` | 生成视频的宽高比 |
| `duration` | `integer` | 生成视频的时长，单位：秒（与 frames 二选一返回） |
| `frames` | `integer` | 生成视频的帧数（与 duration 二选一返回） |
| `framespersecond` | `integer` | 生成视频的帧率 |
| `generate_audio` | `boolean` | 是否包含同步音频（仅 seedance 2.0 & 2.0 fast、seedance 1.5 pro 返回） |
| `tools` | `object[]` | 本次请求实际使用的工具（未使用时不返回） |
| `safety_identifier` | `string` | 终端用户的唯一标识符（原样返回） |
| `priority` | `integer` | 当前请求的执行优先级 |
| `draft` | `boolean` | 是否为 Draft 视频（仅 seedance 1.5 pro 返回） |
| `draft_task_id` | `string` | Draft 视频任务 ID（基于 Draft 视频生成正式视频时返回） |
| `service_tier` | `string` | 实际处理任务使用的服务等级 |
| `execution_expires_after` | `integer` | 任务超时阈值，单位：秒 |
| `usage` | `object` | 本次请求的 token 用量 |

### status 状态说明

| 状态 | 说明 |
|------|------|
| `queued` | 排队中 |
| `running` | 任务运行中 |
| `cancelled` | 取消任务（取消状态 24h 自动删除，仅支持排队中状态的任务被取消） |
| `succeeded` | 任务成功 |
| `failed` | 任务失败 |
| `expired` | 任务超时 |

### content 对象属性

| 参数 | 类型 | 说明 |
|------|------|------|
| `video_url` | `string` | 生成视频的 URL，格式为 mp4。有效期 24 小时。推荐配置 TOS 数据订阅功能自动转存 |
| `last_frame_url` | `string` | 视频的尾帧图像 URL。有效期 24 小时。仅在创建时设置 `"return_last_frame": true` 时返回 |

### error 对象属性

| 参数 | 类型 | 说明 |
|------|------|------|
| `code` | `string` | 错误码，详见[错误处理](https://www.volcengine.com/docs/82379/1299023#.5pa56Iif6ZSZ6K-v56CB) |
| `message` | `string` | 错误提示信息 |

### tools 对象属性

| 参数 | 类型 | 说明 |
|------|------|------|
| `type` | `string` | 工具类型，如 `web_search`（联网搜索工具） |

### usage 对象属性

| 参数 | 类型 | 说明 |
|------|------|------|
| `completion_tokens` | `integer` | 模型生成视频消耗的 token 数量，可作为计费对账依据。**说明：** seedance 2.0 系列模型存在最低 token 用量限制，如果实际用量 ＜ 最低用量，本字段返回最低 token 用量 |
| `total_tokens` | `integer` | 本次请求消耗的总 token 数量。视频生成模型不统计输入 token（输入 token 为 0），故 `total_tokens` = `completion_tokens` |
| `tool_usage` | `object` | 使用工具的用量信息 |
| `tool_usage.web_search` | `integer` | 实际调用联网搜索工具的次数（仅开启联网搜索时返回） |

## 示例

### 请求示例

```bash
TASK_ID="your_task_id"
curl -X GET "https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks/$TASK_ID" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ARK_API_KEY"
```

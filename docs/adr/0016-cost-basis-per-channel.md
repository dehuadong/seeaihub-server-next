# 成本价按渠道各自的口径取数：APIMart 取上游声明的 `cost`，AIHubMix 按已发布费率自算

平台**不假设成本一定能由某一种量算出来**——成本怎么取数跟着渠道自己的计费方式走：APIMart 直接给出 `cost`，那就是它的实际成本（含账号倍率，不可复现），平台不再按 token × 公开费率反算；AIHubMix 不给任何金额字段，成本只能按分项 token × 已发布费率自算；将来接入按次数或按张数计费的渠道（例如豆包），成本就按该渠道的计费单位取数。

**计量事实与成本是两个量。** 计量事实用于结算，它跟着渠道的计费方式走，没有"必须统一成 token"这回事——渠道按 token 计费就取分项 token，直接声明金额就用那句金额，按次数/张数计费就取次数/张数；平台的要求只有一条：证据是**带单位的计量量**，且能唯一落到该 Offering 已声明的计价维度（[0010](./0010-metering-evidence-is-unit-bearing.md)）。`cost` 只用于核成本，不替代计量事实。

**后果**：换渠道就换成本口径，逐笔账目按渠道分别取数，不能跨渠道套同一套算法；平台对外价与账号折扣是否让利属后期产品决定，不在本条。

# 平台结果只认自有对象存储中的 Asset，先归档再标成功

上游图片结果不是平台结果。成功任务必须先把结果归档到自有对象存储并完成校验，**然后**才能把 Job 标记为成功；上游给出的临时位置或临时凭证不返回给调用方，也不作为永久结果。输入侧 Asset 先做权限、MIME、魔数、大小与摘要校验，再由 Adapter 编码成上游接受的形式，平台只把 Asset 引用绑定到模型声明的参数上。

响应解析、解码、校验或归档失败导致结果或计费状态不确定时进对账，**不得重新生成图片**；只有将来发布的执行策略能给出可查询的任务标识，才允许在同一 Attempt 内恢复下载与归档。业务表不长期保存大段媒体内容。

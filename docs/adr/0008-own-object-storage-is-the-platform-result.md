# 平台结果只认自有对象存储中的 Asset，先归档再标记成功

上游图片结果不是平台结果。AIHubMix 输出 URL 约 30 分钟失效且下载需同一 Bearer，因此成功任务必须先把结果归档到自有对象存储、完成校验，**然后**才能把 Job 标记为成功；上游 URL 与 Bearer 不返回给平台调用方，也不作为永久结果。

输入侧：Asset 先完成权限、MIME、魔数、大小与摘要校验，再由 Adapter 编码成上游接受的 URL / data URI / base64 形式；`image` / `images` / `mask` 保留厂商原生字段语义，平台只把 Asset 引用绑定到这些字段（`AssetBinding` 记录原生参数路径、asset_id 与位置）。

当前正式 `/v1` 路径返回 Base64 且没有可查询任务标识。响应解析、Base64 解码、校验或归档失败导致结果或计费状态不确定时进入 Reconciliation Case，**不得重新生成图片**；只有未来发布带可查询任务标识的新执行策略时，才允许在同一 Attempt 内恢复下载/归档。业务表不长期保存大段 Base64。

**来源**：技术设计 v3 与 v4，v5 明确继续有效并补充「Base64 先解码校验归档，随后才能标成功」。

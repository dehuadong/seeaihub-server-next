## 4. 用户口径（违反会被直接指出）

- 中文简体、大白话、**先给结论**、不打流水账；多实测少猜测。
- **命名、术语、文档归属、文件放哪由 Agent 自己裁决**，不要拿这些去问用户；只有产品、合同、成本、风险这类价值判断才请用户裁。
- 一次用户请求 = **一次**上游调用（不许按张拆）；"状态不确定"（超时/5xx/响应读不出/提交阶段连不上）**绝不重投**；不为同一个请求付两次上游成本。
- 平台自担的成本"就是上游实际扣的那笔费用"，**不存在"未定价成本"这种新说法**。
- **ADR 可以就地修订**（用户已授权"ADR 变更，可以做"）：原文与结论段保留为历史，文末追加修订段 + 修订依据，不用新建 ADR；**新建 ADR 需要用户确认**。
- 文档按 `docs/AGENTS.md`：一个事实一个家、写当前状态、别造垃圾文档。

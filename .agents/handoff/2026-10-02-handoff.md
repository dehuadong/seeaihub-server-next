# 交接：后台账户与客户详情页纠偏（2026-10-02）

本文件接替 [2026-09-30 交接](2026-09-30-handoff.md)，供后续执行代理从用户指出的页面问题继续。决定与验收以工作项和 Spec 为准；这里记录位置、当前阻塞与开工顺序。

## 当前事实

- 用户实测指出：后台“账户列表”点行后，在同一页面下方追加“选中账户”；后台“找客户”点“详情”后，也在同一页面下方追加客户卡片。两处都不符合用户现在要求的“列表进入独立详情页”。
- 已关闭的 [#41](https://github.com/dehuadong/seeaihub-server-next/issues/41) 把“找账户和选中摘要留在主页面，四个操作用弹层打开”写成“用户已选择”。用户于 2026-10-02 明确指出这项归因错误。[#39](https://github.com/dehuadong/seeaihub-server-next/issues/39) 的初稿曾写独立详情，后续评论又撤销该方案；两段历史不能替代本次明确纠正。
- 当前实现仍是同页布局：`apps/web/src/console/pages/Accounts.tsx` 的 `selected` 在列表后渲染 `AccountActions`；`apps/web/src/console/pages/Customers.tsx` 的 `selected` 在查找列表后渲染详情卡片。管理员 `useHashRoute` 目前只识别工作区，不识别单个对象详情。
- [#43](https://github.com/dehuadong/seeaihub-server-next/issues/43) 和 `docs/design/0014-customer-console-navigation-and-history.md` 负责**客户自助控制台**。本次纠偏针对**管理员后台的“账户”“客户”两处**，不改 #43、#51、#52 的范围。

## 执行代理要实现的范围

以 #53 的 P1–P5 和已接受的 Spec v15 为准：

1. `#/accounts` 只显示查找、列表与建账户；点行、按 id 查看或建账户成功，进入 `#/accounts/{account_id}`。详情页不出现列表，显示金额、标签及充值、充值记录、扣费记录、API Key；四个模块在详情内切换，一次只显示当前模块。
2. `#/customers` 只显示开户、查找与列表；点“详情”或开户成功进入 `#/customers/{customer_id}`。详情页不出现查找列表，可看客户资料、进入关联账户详情并签发一次性重置令牌。
3. 新增管理员只读 `GET /api/v1/accounts/{account_id}/summary`（既有 `AccountSummary` 字段）与 `GET /api/v1/customers/{customer_id}`（既有 `CustomerView` 字段）；不存在为 404。账户金额仍读既有 `GET /api/v1/accounts/{account_id}`，不改旧接口响应。
4. 两处详情都能直接打开与刷新；前进后退、返回列表时恢复本次查找条件；无会话直达先登录且不取管理数据；对象不存在时不留下旧数据。地址不放凭据或一次性明文。
5. 保留充值防重复、三个金额口径、标签写入、真实资金记录、API Key 明文只展示一次和吊销确认。`apps/web/e2e/admin-account-modules-in-layers.spec.ts` 等按旧同页布局断言的用例需要随合同更新，不能拿旧用例的通过当新布局的验收。

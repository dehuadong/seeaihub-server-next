# AGENTS.md — Agent Notes

这里放本仓库的工程决定与交付理由。路径已经编码了生命周期与分类，文件内格式由 [README](./README.md) 拥有，`node scripts/decisions/check.mjs` 强制——写记录前先读这两处，不要照着相邻文件猜格式。正文写法（含术语）遵循 [`docs/AGENTS.md`](../../docs/AGENTS.md) 的写作规则与 slop 清单。

- **新建前先搜同主题的既有记录**，判断是更新它、另建一条，还是取代它。主题相近不等于同一条决定，别重复记一份。
- **`implemented/` 记录与实际交付保持同步**：路径、符号名、默认值、机制描述跟着代码在同一次变更里改掉。只改事实，不改决定；要推翻决定就新建记录并双向链接。
- **完全取代时可以并入持有该决定的记录并删掉旧文件**，前提与步骤见 [README § 何时需要写](./README.md#何时需要写)；部分取代不行，两条记录互相链接，各自更新仍然适用的事实。
- **记录不是合同或决策正文的家**：这里只引用权威工件，不复制；位置见 [工件注册表](../../docs/agents/artifacts.md)。
- **不生成集中索引**：`{生命周期}/{分类}/` 目录树就是清单；根目录出现 `INDEX.md` 会被检查拒绝。
